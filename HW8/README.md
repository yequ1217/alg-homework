## 題目重點

分別用下列五種方法解決旅行推銷員問題（TSP）：

1. 改良法
2. 爬山演算法
3. 模擬退火法
4. 梯度下降法
5. 貪婪演算法

TSP 的目標是找一條經過所有城市恰好一次、最後回到起點的最短迴路。

## 共同基礎：2-opt 交換

除了貪婪法以外，其餘方法都用 **2-opt** 作為鄰居產生方式：選兩條邊 `(i, i+1)`、`(j, j+1)`，把中間的區段反轉。若原本距離為：

```text
d(i, i+1) + d(j, j+1)
```

反轉後變成：

```text
d(i, j) + d(i+1, j+1)
```

兩者相減就是這次交換的 delta。delta < 0 代表路徑變短。

## 五種方法

### 1. 貪婪演算法（Nearest Neighbor）

從起點開始，每次走到最近的未拜訪城市。速度快，但容易卡在不好的選擇，是後面方法的初始解。

### 2. 改良法（Greedy + 2-opt）

先用貪婪法建一條路，再反覆尋找「最好的 2-opt 交換」來改進，直到沒有任何交換能讓路徑變短。屬於局部搜尋。

### 3. 爬山演算法（Hill Climbing）

隨機產生初始路徑，隨機挑一組 2-opt 交換：

- 變短就接受
- 沒變短就丟棄

連續多次沒有改進就停止。只接受更好的解，因此容易卡在局部最佳解。

### 4. 模擬退火法（Simulated Annealing）

類似爬山，但允許「以一定機率接受變差的解」：

```text
若 delta < 0：一定接受
若 delta >= 0：以 exp(-delta / T) 的機率接受
```

溫度 `T` 會逐漸下降（`T *= alpha`），前期可以跳出局部最佳，後期逐漸收斂。

### 5. 梯度下降法（最陡 2-opt）

把「所有 2-opt 交換」看成離散梯度方向，每一輪挑 delta 最負（改進最多）的交換，也就是最陡下降法。這不是連續函數的梯度，而是 TSP 上的離散類比。

## 執行方式

```powershell
python tsp.py
```

程式固定隨機種子，使用 15 個隨機城市，讓五種方法在同一組資料上比較。

## 比較

| 方法 | 類型 | 優點 | 缺點 |
| --- | --- | --- | --- |
| 貪婪法 | 啟發式 | 非常快 | 解通常較差 |
| 改良法 | 局部搜尋 | 快且穩定 | 只到局部最佳 |
| 爬山演算法 | 局部搜尋 | 簡單 | 容易卡在局部最佳 |
| 模擬退火法 | 全域隨機搜尋 | 可跳出局部最佳 | 參數多、較慢 |
| 梯度下降法 | 最陡下降 | 收斂快 | 仍可能卡在局部最佳 |

## 討論

- 在這組 15 個城市的例子上，除了貪婪法以外，四種局部搜尋都收斂到同一條長度 `284.9086` 的路徑，這是一組局部最佳解。
- 爬山法與模擬退火法的執行時間明顯較長，因為它們做了大量隨機嘗試。
- 改良法從貪婪解出發，只花了很少時間就到達同樣的局部最佳，是「好的初始解 + 2-opt」的典型效果。
- 若城市數更多，可能需要多次隨機重啟（random restart）或更強的演算法（如 LKH）才能避免局部最佳。

## 心得

- 啟發式方法不保證最佳解，但能在合理時間內得到不錯的答案。
- 初始解的好壞影響很大：貪婪法 + 2-opt 往往就能贏過單純的隨機搜尋。
- 模擬退火的「接受較差解」機制，是逃離局部最佳解的關鍵。
