# HW2 - 四條遞迴方程式的精確解與 Big O

## 推導

### 1. T(n) = T(n-1) + 8, T(1) = 1

逐步展開：

```text
T(n) = T(n-1) + 8
     = T(n-2) + 8 + 8
     = ...
     = T(1) + 8(n-1)
     = 1 + 8n - 8
     = 8n - 7
```

- 精確解：`T(n) = 8n - 7`
- Big O：**Θ(n)**

### 2. T(n) = 2T(n-1) + 9, T(1) = 1

令 `S(n) = T(n) + 9`：

```text
S(n) = T(n) + 9 = 2T(n-1) + 18 = 2(T(n-1) + 9) = 2S(n-1)
S(1) = T(1) + 9 = 10
S(n) = 10 * 2^(n-1)
T(n) = 10 * 2^(n-1) - 9 = 5 * 2^n - 9
```

- 精確解：`T(n) = 5 * 2^n - 9`
- Big O：**Θ(2^n)**

### 3. T(n) = 2T(n/2) + 1, T(1) = 1

令 `n = 2^k`，每層展開後相加：

```text
T(n) = 2T(n/2) + 1
     = 4T(n/4) + 2 + 1
     = 8T(n/8) + 4 + 2 + 1
     = ... 
     = n*T(1) + (1 + 2 + 4 + ... + n/2)
     = n + (n - 1)
     = 2n - 1
```

也可用 Master Theorem：`a = 2, b = 2, f(n) = 1 = O(n^(1-ε))`，屬於 Case 1，得到 `Θ(n)`。

- 精確解（n 為 2 的次方）：`T(n) = 2n - 1`
- Big O：**Θ(n)**

### 4. T(n) = T(n/2) + 1, T(1) = 1

```text
T(n) = T(n/2) + 1
     = T(n/4) + 2
     = ...
     = T(1) + log2(n)
     = 1 + log2(n)
```

- 精確解（n 為 2 的次方）：`T(n) = 1 + log2(n)`
- Big O：**Θ(log n)**
