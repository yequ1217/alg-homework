# HW1 - 四種 power2n 寫法與效能比較

## 題目重點

完成 `power2n(n)` 的四種寫法，自行撰寫主程式測試，比較快慢，並找出哪一種在 `n = 100` 時跑不出來。

## 四種寫法

| 方法 | 程式寫法 | 遞迴式 | 時間複雜度 | 額外空間 |
| --- | --- | --- | --- | --- |
| 1 | `2 ** n` | 無 | 內建快速冪，約 O(log n) 次大數乘法 | O(1) |
| 2a | `power2n(n-1) + power2n(n-1)` | T(n) = 2T(n-1) + 1 | O(2^n) | O(n) 遞迴堆疊 |
| 2b | `2 * power2n(n-1)` | T(n) = T(n-1) + 1 | O(n) | O(n) 遞迴堆疊 |
| 3 | 遞迴 + 字典查表 | 每個 n 只計算一次，O(n) | O(n) | O(n) 查表 + O(n) 堆疊 |

## 執行方式

```powershell
python power2n.py
```

## 執行結果

```text
-- n = 20（全部方法都可跑）--
方法 1：2 ** n                  n=20  耗時   0.000001 秒  位數 7
方法 2a：T(n-1)+T(n-1)          n=20  耗時   0.097872 秒  位數 7
方法 2b：2*T(n-1)               n=20  耗時   0.000003 秒  位數 7
方法 3：遞迴+查表                   n=20  耗時   0.000014 秒  位數 7
四種結果一致: True

-- n = 100（題目要求的測試值）--
方法 1：2 ** n                  n=100  耗時   0.000002 秒  位數 31
方法 2b：2*T(n-1)               n=100  耗時   0.000019 秒  位數 31
方法 3：遞迴+查表                   n=100  耗時   0.000028 秒  位數 31
方法 2a 在 n = 100 時需要約 2^100 次呼叫，實際上跑不出來，故略過。
結果一致: True
```

## 結論

1. **方法 2a 是唯一跑不出來的**：遞迴式為 `T(n) = 2T(n-1) + 1`，呼叫次數約 `2^(n+1) - 1`；`n = 100` 需要約 `2^100` 次呼叫，遠超電腦可行範圍。
2. **方法 2b 只把前一個結果乘 2**，遞迴式是 `T(n) = T(n-1) + 1`，因此是線性 O(n)，`n = 100` 很快。
3. **方法 3 用查表避免重複計算**，把方法 2a 的指數時間降成線性時間，是典型的動態規劃（記憶化）技巧。
4. **方法 1 內建 `2 ** n` 最快**，因為底層用快速冪處理大整數。
