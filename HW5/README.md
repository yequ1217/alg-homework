# HW5 - 河內塔、符號微分、無迴圈泡沫排序

## 1. 河內塔

### 遞迴版

```text
hanoi(n, src, aux, dst):
    若 n == 1：把盤子從 src 移到 dst
    否則：
        hanoi(n-1, src, dst, aux)
        把盤子從 src 移到 dst
        hanoi(n-1, aux, src, dst)
```

### 非遞迴版（禁止遞迴）

用一個明確的堆疊模擬上面的遞迴呼叫。每個工作記錄 `(盤子數, 來源, 輔助, 目標, 是否已展開)`：

- 未展開：依「後進先出」的相反順序 push 三個工作
- 已展開：代表此時要真正移動盤子

兩者產生的移動序列完全相同，移動次數為 `2^n - 1`，時間複雜度 `O(2^n)`。

## 2. 符號微分

`sym_diff(expr, var="x")` 的流程：

1. 用 `ast.parse` 把字串解析成語法樹。
2. 遞迴套用微分規則：

| 原式 | 微分結果 |
| --- | --- |
| 常數 `c` | `0` |
| 變數 `x` | `1`（其他變數為 `0`） |
| `u + v` | `u' + v'` |
| `u - v` | `u' - v'` |
| `u * v` | `u'v + uv'`（乘法規則） |
| `u / v` | `(u'v - uv') / v^2`（除法規則） |
| `u^n`（n 為常數） | `n * u^(n-1) * u'`（冪次規則） |

3. 用 `simplify` 化簡（合併常數、去掉 0 與 1）。
4. 轉回字串輸出。

## 3. 自製 map / filter / reduce 與無迴圈泡沫排序

三個高階函式都用遞迴實作，沒有使用 `for` / `while`：

```python
my_map(f, xs)        # 逐項套用 f
my_filter(pred, xs)  # 保留 pred 為真的項
my_reduce(f, xs, init)  # 由左而右摺疊
```

泡沫排序的每一趟用 `my_reduce` 完成：狀態是 `(已排好的前段, 目前帶在手上的最大值)`，把最大值一路往後推。整趟結束後，遞迴排序剩下的前 `n-1` 項。整個過程沒有迴圈。

## 複雜度

| 項目 | 時間 | 空間 |
| --- | --- | --- |
| 河內塔 | O(2^n) | O(n) |
| 符號微分 | 與表示式節點數成正比（多項式時間） | O(節點數) |
| 泡沫排序 | O(n^2) | O(n)（遞迴堆疊） |
